# Folio Symbol Logo Prompts

Use these for image generation passes where the goal is a memorable app icon, not a lettermark.

## Master Board Prompt

Create a premium app icon concept board for a macOS app named Folio.

Product context: Folio is a local-first meeting transcription app. It privately captures conversations, turns audio into notes, and keeps meetings searchable on the user's own machine.

Design goal: Do not make a letter F. Do not make anything Facebook-like. Create memorable symbol-first icons with an ownable silhouette.

Style target: polished modern app icons, friendly but professional, simple enough to remember from one glance. Rounded-square app icon tiles. Soft blue, violet, lavender gradient similar to the Codex app icon, with white or near-black backgrounds. Smooth vector-like rendering, clean negative space, minimal details.

Create 8 distinct alternatives in a 4x2 grid:

1. A small listening notebook creature holding private notes.
2. A folded page with a waveform tucked inside.
3. A private audio vault with a waveform seal.
4. A friendly transcript blob with note lines.
5. A meeting bubble with soft headphones.
6. A paperclip-shaped sound loop.
7. A tiny archive box with an ear-like curve and waveform.
8. A sealed note with a waveform smile.

Avoid generic microphones, plain headphones, plain documents, letters, initials, and copied brand mascots. Tiny labels A-H only.
