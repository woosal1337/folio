# App brand icons

Vendored glyphs for the Settings → Notifications app picker.

Sources (permissively licensed; copied here so the app needs no
runtime icon dependency):

- chrome, safari, firefox, arc, zoom, meet, webex, discord — Simple Icons
  (https://simpleicons.org), CC0-1.0.
- slack, teams — Bootstrap Icons (https://icons.getbootstrap.com), MIT.
- facetime — Bootstrap Icons `camera-video-fill` (neutral video glyph;
  FaceTime has no brand glyph in these sets), MIT.

All are single-path, no fill, so they inherit `currentColor`.
