# Folio — rules for AI coding agents

Binding rules for every AI coding session in this repository. Read before
making any change.

## No comments. Ever.

Do not write comments in source code — not in Rust, TypeScript, JavaScript,
or CSS. This means:

- No inline `//` comments.
- No block `/* ... */` comments.
- No doc comments: `///`, `//!`, or JSDoc `/** ... */`.
- No section-divider or banner comments.

Code must explain itself through clear names and small functions. If
something genuinely needs prose, put it in the PR description or in
`docs/` — never in the source.

The only allowed exceptions are load-bearing machine directives that change
tool behavior (never prose):

- `// eslint-disable*`, `// eslint-enable*`
- `// @ts-expect-error`, `// @ts-ignore`, `// @ts-nocheck`
- `/// <reference ... />` triple-slash directives
- the auto-generated header line in `src/shared/types/*.ts` (`// This file was generated by ts-rs ...`)

When editing a file that still contains comments, remove them as you go.

## Everything else

See `AGENTS.md` for commands and conventions and `docs/CODE_STYLE.md` for
the full style contract.
